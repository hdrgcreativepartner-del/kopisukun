# Kopi Sukun — Clean Apple-like Menu

Final UI direction:
- Simple, professional, clean.
- No big-screen / catalog treatment.
- Menu is presented as compact, elegant list rows.
- Flat category icons only; no product photos.
- Desktop and mobile use the same clean list system.
- Clicking a menu opens a focused product detail modal with poetic description and price.
- Responsive and touch-friendly.
- Offline ordering only.
- Admin only manages menu name, category, and price.
